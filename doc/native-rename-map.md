# 上游 flutter_inappwebview → Aqutter：原生端、channel、JS 與 plugin 名稱對照

本表供從上游 `flutter_inappwebview` 遷移，或在各原生端核對共用字串時使用。Dart 公開 API 的對照見 `doc/dart-rename-map.md`。**不保留舊名稱**。

## 規則

- Channel 前綴：`com.pichillilorenzo/` → `com.github.aqutter/`；後綴去掉 `flutter_` 與 `inapp`（見下表）。
- JS：全域 `window.flutter_inappwebview` → `window.aqutter`；事件 `flutterInAppWebViewPlatformReady` → `aqutterPlatformReady`；Web 端互通全域 `window.flutter_inappwebview_plugin` → `window.aqutterWeb`；內部變數 `_flutter_inappwebview_*` → `_aqutter_*`。**硬切換，不留舊名稱**。
- Plugin：`InAppWebViewFlutterPlugin` → `AqutterCorePlugin`（Windows `AqutterCorePluginCApi`）；`dartPluginClass` 改為 `Aqutter<平台>WebViewPlatform`。
- 原生類別（Kotlin／Swift／C++）：前綴 `Aqutter`、移除 `InApp`（與 Dart 同一套規則）；小寫識別字 `inApp` → `aqutter`；常數 `IN_APP_` → `AQUTTER_`；C++ 命名空間 `flutter_inappwebview_plugin` → `aqutter_core_plugin`。
- 檔案與目錄：去掉 `in_app_`、`inappwebview` → `webview`；類別檔名跟著類別名。
- 持久化與系統可見：Android 資料庫 `CredentialDatabase.db` → `aqutter_credential_database.db`（首次開啟時自動搬移舊檔）；FileProvider authority `<applicationId>.flutter_inappwebview_android.fileprovider` → `<applicationId>.aqutter_core.fileprovider`；intent key `com.pichillilorenzo.flutter_inappwebview.ChromeCustomTabs.*` → `com.github.aqutter.ChromeCustomTabs.*`；Linux 環境變數 `FLUTTER_INAPPWEBVIEW_LINUX_DISABLE_GL` → `AQUTTER_LINUX_DISABLE_GL`。
